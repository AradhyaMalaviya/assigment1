# Full Stack Developer Assignment

This assignment is required to move forward in the selection process for the **Full Stack Developer** position.

The task is designed to evaluate your **technical skills**, **problem-solving ability**, and **decision-making approach**, with a strong focus on **frontend architecture and migration capability**.

Please read all instructions carefully before starting.

---

## Assignment: Frontend Migration Task

### Objective

Migrate the existing frontend using **any modern frontend framework of your choice**, while keeping the **backend logic and database structure completely unchanged**.

You are free to choose the framework you believe is most suitable for a **production-grade application**. Examples include, but are not limited to:

- Next.js
- Nuxt
- Remix
- Astro
- SvelteKit
- Any other modern, well-structured frontend framework

The framework choice itself is **not being judged**. What matters is **how well you design, structure, and implement the solution**.

---

### Project Repository

https://github.com/thedevimapro/assignment

---

### Instructions

- Read the README file carefully before starting
- Do **not** modify backend logic or database structure
- You may refactor frontend code as required
- Choose a framework and architecture you can confidently justify
- Follow clean, maintainable, and production-ready coding practices
- Use proper folder structure, naming conventions, and scalability patterns

---

### Evaluation Criteria

- Code quality, clarity, and maintainability
- Correct and effective usage of the chosen framework
- Project structure and scalability
- Architectural and decision-making clarity
- Attention to detail
- Overall production readiness

Rushed, incomplete, or poorly structured submissions may not be considered.

## Submission Requirements

- Upload your migrated frontend project to GitHub
- Share the repository link as your final submission
